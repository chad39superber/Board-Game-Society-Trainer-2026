## 🎮 About the Game

Board Game Society is a turn-based digital board game with RPG elements and 1980s VHS horror aesthetics. Developed by Jetebra Games, it released on August 28, 2026. Players control teenage archetypes, explore the cursed Timber Falls setting, roll dice, fight monsters, collect loot, and race toward the Boss.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Board Game Society**. This trainer adds optional quality-of-life controls for Board Game Society, including health protection, improved dice outcomes, faster progression, and easier handling of board exploration, loot collection, monster encounters, and boss races.

**Target Audience:** Players who want a more relaxed solo experience, easier experimentation with dice-based gameplay, faster access to loot and board events, or additional control during monster and boss encounters.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Board movement is driven by dice rolls. Activate Dice Roll Control before rolling when you want more predictable movement, then disable it when normal randomness is preferred. Use Teleport Assistance only when a teleport interaction is available.

### Tools & Inventory

Loot is collected while exploring the board. Activate Loot Multiplier before collecting items to increase the resulting amount. Avoid switching the option repeatedly during the same pickup sequence.

### World & Environment

Explore the Timber Falls boards, including Camp Kilgore and Carnival Carnage, while watching for events, healing points, teleport interactions, shortcuts, and monster encounters. The trainer is best used after a turn has fully loaded.

### Combat & Weapons

Monster fights are resolved through turn-based dice mechanics. Enable Unlimited Health or Monster Encounter Advantage before starting an encounter. Turn options off after combat has ended to reduce unnecessary game-state changes.
